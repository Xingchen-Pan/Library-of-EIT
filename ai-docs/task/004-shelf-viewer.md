## 目标与开始条件

在 React 应用壳内装载带空间映射的单层模型，提供查看建筑、切层和定位书架的交互。 设计依据见[Viewer 模块与状态](../architecture/core/viewer.md)。

## 实施与验收

实现查看器、楼层和拾取模块；让点击书架与按 ID 定位共用控制入口，接入二维视图。多楼层切换用额外的测试楼层验证。

- [ ] 可旋转、平移、缩放、重置及切层；触摸拖动和书架点击可区分，按 ID 与点击可选中同一书架。
- [ ] 切层后隐藏对象无法被点选；模型失败可重试，WebGL 不可用时仍可查看可用的二维信息。

## 工作记录与回退

2026-11-23 已取得 002 的 React 应用壳。在 003 的实馆资产交付前，使用两层程序化样例实现平面与三维选架、视角控制及 WebGL 降级。桌面鼠标和模拟触屏已验证实际三维拾取，证据见[002 记录](records/002-react-ts7.md)。真实 GLB 加载、重试和视角重置仍待验收。保留二维展示路径，卸载或重试时释放旧场景。
