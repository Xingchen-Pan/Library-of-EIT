# Web 三维导览架构

读者搜索图书、选择馆藏副本后，页面应能回答三个问题：书在哪一层、在哪个书架、从当前起点怎么走。本仓库负责浏览器中的检索界面、模型交互和路线展示。馆藏查询、位置解析和路径计算由独立的 `library-go` 服务提供。[原始方案](https://chatgpt.com/s/t_6b041f0477a48191aa89c8ff6981ca72)

## 首版读者流程

1. 打开导览页。建筑载入后可以旋转、平移、缩放和重置视角。首批模型至少覆盖一个完整楼层，含墙体、入口和可选择的书架。
2. 切换楼层，仅展示该层的室内对象，遮挡视线的外墙可透明显示。读者可直接点选书架，也可搜索书名，从馆藏副本进入定位。两种操作使用同一书架 ID，在楼层图和三维视图上选中同一位置。
3. 手动选择起点或扫描标有位置的二维码，向 Go 请求到目标书架的路线。读者按楼层查看路径、方向和换层位置。有下一层平面图时，即使该层三维模型尚未加载，也能继续看二维指引。
4. 手机浏览器支持触控切层和选架。模型加载失败或浏览器无法创建 WebGL 2 上下文时，读者仍可查看已取得的馆藏位置文字和可用平面图。
