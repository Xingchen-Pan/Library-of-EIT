# 需求与范围

| 场景 | 读者能观察到的结果 | 数据前提 |
| --- | --- | --- |
| 看楼层 | 从平面书架或三维场景选择目标，楼层和详情同步 | 带稳定 ID 的书架清单 |
| 搜书 | 按书名或架号筛选，选择副本后切换到对应楼层 | 包含副本与架号的馆藏数据 |
| 看实馆位置 | 底图、GLB 和书架映射对应同一实测版本 | 已标定的实馆素材和模型清单 |
| 到达书架 | 从起点查看分层路线及换层提示 | Go 服务返回相同模型版本的可达路径 |

示意数据用于验证前两种交互。正式交付包含真实建筑、书架映射以及服务端算路。各阶段交付情况见[任务索引](../task-index.md)。
