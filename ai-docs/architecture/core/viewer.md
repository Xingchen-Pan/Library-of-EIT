# Viewer 模块与状态

目标目录按职责组织。`src/app/` 装配 React 入口和 Provider，`src/features/` 放检索、楼层、书架和导航界面，`src/components/` 放共享控件。场景由 `src/viewer/` 管理，空间映射、网络和界面状态分别进入 `src/spatial/`、`src/api/` 和 `src/stores/`。开发模型从 `public/models/` 加载。

| 模块 | 输入 | 职责与输出 |
| --- | --- | --- |
| BuildingViewer | 模型清单、容器 | 异步装载场景，提供加载、失败与重试状态；管理相机、控制器、尺寸变化以及卸载后的资源释放。 |
| FloorManager | 楼层 ID、外墙显示模式 | 按模型节点分组控制楼层可见性、外墙材质和当前可拾取对象。恢复全楼视图时还原材质。 |
| ShelfManager | 指针命中对象或书架 ID | 从命中网格向上找到带书架标识的节点，通过映射表定位、高亮和清除上次选择。 |
| SpatialManager | 版本化清单、楼层标定 | 构建楼层和书架索引，将楼层平面坐标变换到模型坐标，并提供逆变换。 |
| NavigationViewer | 路线分段、当前楼层 | 绘制当前层路线、方向和目标；在楼梯或电梯连接点提示下一层，切层后接续显示。 |
| BookLocator | 读者选择的馆藏副本 ID | 通过 API 适配层读取位置，返回可定位的楼层和书架 ID，或说明馆藏位置缺失。 |
| ViewerController | 切层、定位、重置视角等意图 | 协调模型就绪、映射校验和相机操作，对 React 暴露统一入口。 |

## 点击书架与检索定位

读者点选当前楼层的书架时，Raycaster 返回网格，ShelfManager 将命中归一为书架 ID。检索定位则从 BookLocator 取得书架 ID。两条路径汇入同一定位操作：核验模型版本、确认楼层与书架匹配、显示该层、更新高亮和详情。点击空白清除选择，主动切层清除上一层的书架高亮。触摸拖动用于相机操作，指针抬起且未形成拖动时才选架。

## 状态所有权

- Zustand 保存当前楼层、选中书架、导航起终点和正在查看的路线段。楼层和选中书架一起更新，二维和三维视图订阅同一选择。
- TanStack Query 按检索条件、副本 ID 或路线端点与模型版本缓存结果。用户快速从副本 A 切到 B 时，只允许 B 的结果触发相机定位；更换端点即撤下旧路线。
- Three.js 场景对象、材质和动画循环属于 BuildingViewer。组件卸载时取消订阅、停止渲染循环并释放其拥有的 GPU 资源；较晚返回的加载结果不能重新挂回旧场景。
